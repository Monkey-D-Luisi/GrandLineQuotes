# Ui - Mobile Client

Mobile client application written in Kotlin with Jetpack Compose Multiplatform. While the project maintains its original multiplatform structure (including iOS and web targets), only the **Android** variant is currently functional and maintained.

## Project Structure

* **composeApp** – Main application module containing shared and platform-specific code
* **gradle** – Gradle wrapper files
* **iosApp** – iOS application target (not currently maintained)
* **kotlin-js-store** – JavaScript/Web target artifacts (not currently maintained)

## Product Flavors and Configuration

API endpoints and other environment-specific settings are defined through product flavors in [`composeApp/build.gradle.kts`](composeApp/build.gradle.kts). Three flavors are available:

### Local
* **Purpose:** Targets the development stack started with `docker-compose.yml` locally
* **GraphQL Endpoint:** `https://grandlinequotes-api-public-dev.local:8443/graphql`
* **API Base URL:** `https://grandlinequotes-api-public-dev.local:8443`
* **Application ID Suffix:** `.local`
* **Version Name Suffix:** `-local`

### Sandbox
* **Purpose:** Used by the automated test script `src/Scripts/Sandbox/run-tests.sh`
* **GraphQL Endpoint:** `http://localhost:5024/graphql`
* **API Base URL:** `http://localhost:5024`
* **Application ID Suffix:** `.sandbox`
* **Version Name Suffix:** `-sandbox`

### Test
* **Purpose:** Points to the remote production-like environment consumed by the published app
* **GraphQL Endpoint:** `https://public.95-217-6-136.sslip.io/graphql`
* **API Base URL:** `https://public.95-217-6-136.sslip.io`
* **Version Name Suffix:** `-test`

## Building the Application

To build an APK for a specific flavor:

```bash
./gradlew :composeApp:assemble<Flavor>Debug
```

**Examples:**

```bash
# Build for Local development
./gradlew :composeApp:assembleLocalDebug

# Build for Sandbox testing
./gradlew :composeApp:assembleSandboxDebug

# Build for Test environment
./gradlew :composeApp:assembleTestDebug
```

## Running Tests

Run unit tests for a specific flavor:

```bash
./gradlew :composeApp:test<Flavor>DebugUnitTest
```

**Example:**

```bash
./gradlew :composeApp:testSandboxDebugUnitTest
```

## Requirements

* **JDK 17** or higher
* **Android SDK** with API levels 24-36 (configurable via `.env` files)
* **Gradle** (wrapper included)

## Android SDK Configuration

The Android SDK path is configured in `local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

This file is automatically generated by the test script or Android Studio. If running Gradle from the command line, ensure `ANDROID_HOME` or `ANDROID_SDK_ROOT` environment variables are set.
